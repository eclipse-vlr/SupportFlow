# Как проверяли Алису AI

22 октября 2026 года проверили `aliceai-llm-flash` на учебных обращениях. На каждый пример — один запрос, таймаут 30 секунд, лимит ответа 1500 токенов.

| Набор | Верные категории | Ошибки API | Токены, вход / выход |
|---|---:|---:|---:|
| 32 обращения, по 8 на категорию | 32 из 32 | 0 | 9 015 / 2 840 |
| 4 повторных примера после правки инструкции | 4 из 4 | 0 | 1 349 / 315 |

В основном прогоне медианное время ответа — 7,11 секунды. Это время вызова модели, без ожидания в очереди.

## Что получилось

На этом наборе категории определились верно, все ответы прошли проверку структуры. Но в черновиках встречались лишние обещания: «найдём решение», «учтём при обновлениях», «сообщим новости».

Инструкцию уточнили и повторили четыре примера. Часть обещаний осталась, поэтому черновики проверяет оператор. Полный набор после последней правки инструкции повторно не запускался.

Эти прогоны были без базы знаний. После её добавления отдельно проверили три обращения через приложение: повторное списание, ошибку CSV и благодарность. Категории верны, первые два получили подходящую статью, третье — ни одной. Всего 1 594 входных и 256 выходных токенов, ошибок API нет. В ответе про списание осталось «мы разберёмся»; база не устранила все лишние обещания.

Набор небольшой и синтетический, на реальных обращениях результат может отличаться. Приоритеты отдельно не размечали, а черновики просмотрели вручную.

Примеры и полные ответы: [основной набор](../testdata/eval.json), [первый отчёт](eval-alice-2026-10-22.json), [повторная проверка](eval-alice-replies-2026-10-22.json). Первый прогон соответствует коду из коммита `776fcb4`.

## Как повторить

С заполненным `.env` и `LLM_PROVIDER=yandex`:

```powershell
docker compose --profile tools run --rm --no-deps --env-from-file .env check go run ./cmd/eval -limit 0 -report eval-new.json
```

Команда делает платные запросы. Для короткой проверки задайте `-limit 5`. Отчёт содержит сообщения, ответы, время и токены; существующий файл не перезаписывается, поэтому для нового прогона выберите новое имя.
