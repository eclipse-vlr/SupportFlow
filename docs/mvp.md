# Что проверено

MVP работает локально: обращение → Алиса AI → оценка и правки → подтверждение → закрытие.

В браузере проверили создание обращения, две правки и подтверждение ответа. Затем сохранили изменение через API и попробовали записать старую версию из формы: приложение показало конфликт и оставило несохранённый текст на месте. После загрузки актуальной версии ответ удалось подтвердить.

Исходный текст модели сохранился отдельно. Перезапуск приложения не изменил ответ и пять записей истории. Старые правки перенеслись при обновлении базы. Кнопка копирования доступна только для подтверждённого текста и отключается при редактировании.

С базой знаний проверили три настоящих запроса: списание и ошибка CSV получили подходящие статьи, благодарность — ни одной. Статья открывается в карточке, просмотр не стирает несохранённый черновик. После правки и подтверждения источник остался прежним. Старые обращения открываются без источников.

![История правок](supportflow-history.png)

Поиск по теме и сообщению работает вместе с фильтром «Ждут проверки». После подтверждения обращение исчезает из этого списка. В браузере прошли путь от готового примера до оценки, подтверждения, закрытия и повторного открытия. Сохранение оценки не стирает набранный ответ. Закрытие и оценка сохранились после перезапуска. Закрытый ответ доступен для копирования, но защищён от правок. Примеры только заполняют форму и не вызывают модель до создания обращения. [Скриншот](supportflow-workflow.png).

## Тесты

```powershell
docker compose --profile tools run --rm check
```

Проверяются форматирование, `go vet`, гонки, работа с PostgreSQL и зависимости. Есть тесты на конкурентные правки и закрытие, сохранение оценок, поиск, повтор запроса, откат истории и перенос старой базы без дублей. Платный API не вызывается.

Проверка качества модели вынесена [отдельно](evaluation.md).

Для демонстрации выберите пример в форме, дождитесь анализа, оцените черновик, поправьте и подтвердите ответ. Закройте обращение и найдите его в «Закрытых». Без ключа можно использовать `LLM_PROVIDER=demo`.

Подтверждение сохраняет ответ в приложении. Отправка клиенту, учётные записи и несколько операторов в этот MVP не входят.
