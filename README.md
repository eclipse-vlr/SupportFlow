# SupportFlow

Локальное рабочее место поддержки на Go с Алисой AI. Модель разбирает обращение и готовит ответ, оператор проверяет и подтверждает результат.

![SupportFlow](docs/supportflow-preview.png)

## Возможности

- Приём обращений, очередь в PostgreSQL и обработка в фоне.
- Категория, приоритет, краткое описание и черновик ответа от модели.
- Правки и подтверждение оператором с сохранением каждой версии.
- Исходный ответ модели, история изменений и защита от перезаписи из старой вкладки.
- Фильтры, повторные попытки и тёмный интерфейс.

## Запуск

Нужен Docker Desktop с Linux containers.

```powershell
git clone https://github.com/eclipse-vlr/SupportFlow.git
cd SupportFlow
Copy-Item .env.example .env
```

Для Алисы AI заполните в `.env`:

```dotenv
LLM_PROVIDER=yandex
YANDEX_API_KEY=секретный_ключ
YANDEX_FOLDER_ID=ID_каталога_Yandex_Cloud
```

[Получение ключа](https://aistudio.yandex.ru/ru/docs/ai-studio/operations/get-api-key). Модель по умолчанию — `aliceai-llm-flash`; для запросов нужны доступ к API и биллинг. Чтобы попробовать без ключа и платных запросов, оставьте `LLM_PROVIDER=demo`.

```powershell
docker compose up --build -d
```

Откройте [localhost:8080](http://localhost:8080), создайте обращение, поправьте черновик и подтвердите ответ. Сохранённые версии появятся в истории карточки. После изменения `.env` пересоздайте приложение: `docker compose up -d --force-recreate app`.

## Проверка

```powershell
docker compose --profile tools run --rm check
```

Форматирование, `go vet`, тесты с `-race` и PostgreSQL, проверка зависимостей. Платный API в тестах не вызывается.

На учебном наборе Алиса определила 32 категории из 32 верно. Методика, оба прогона и замечания к черновикам — в [отчёте оценки](docs/evaluation.md). Это небольшой синтетический набор; ответы модели требуют проверки человеком.

## Подробности

Go 1.26+, PostgreSQL 17, pgx, HTML/CSS/JavaScript без фронтенд-фреймворка. [Архитектура, API и настройки](docs/development.md) · [Проверка MVP](docs/mvp.md).

MVP рассчитан на одного локального оператора. Авторизации и отправки ответа клиенту нет: подтверждение сохраняет ответ в приложении. Ключ остаётся в локальном `.env`; при работе с LLM текст обращения передаётся Яндексу.

Остановка с сохранением данных: `docker compose down`.
